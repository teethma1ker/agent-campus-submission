# 05 复盘

## 实际用时

约 2.5 小时（含数据构造、工具、循环、测试、证据与文档）。未超出题目建议的 3 小时。

## 最难的问题

1. **把「动态决策」做实**：最初 Mock 采用预演动作列表，虽然能跑通但对工具结果不敏感，不符合题目要求。改为「每一步读取真实 Trace、按观察重组下一步」后，才真正体现补查/换策略/重试/结束的分支。
2. **防虚报**：模型可能声称保存成功或已发布。解决方式不是靠提示词，而是报告只认工具真值 + 声明核对兜底，并让「发布」在系统中根本不存在。
3. **确认边界**：冲突时既要给建议又不能改硬性时间，最终采用「保留原时间 + 待确认草稿 + 显式建议」的组合，避免越权。

## 学习收获

- ReAct 的工程重点不在提示词，而在**观察回填、工具协议校验和系统级兜底**；
- 幂等、故障注入、声明核对这些「不起眼」的防御，是评分里区分高低分的关键；
- 把 mock 与真实模型放在同一循环、同一工具下，可以让离线证据与真实运行保持一致。
